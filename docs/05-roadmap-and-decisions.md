## 3. MVP 验收

- [ ] Agent 登记/编辑/停用/查询正常，按部门展示；
- [ ] 每个 Agent 唯一关联一个源 Agent 标识和来源环境；
- [ ] Run ID + Agent ID 幂等，同一 Run 上报多次只计一次；
- [ ] 能查看成功、失败、运行中、取消 Run，技术成功率分母只含成功/失败；
- [ ] 无法采集时间/耗时时不造数据，表明来源与最近采集时间；
- [ ] 总览、单 Agent 列表、日期趋势、排行一致，能定位失败 Run；
- [ ] 日志不存原始 Prompt、客户/员工隐私，API 认证/分页/最小读权限；
- [ ] Vue 复刻原型布局，演示运行和真实数据在不同 Provider/环境；
- [ ] 生产页面不宣称业务任务成功、真实工时节约、已结算成本或 ROI。
