# 02｜产品需求 PRD — 极简 Agent 日志看板

> **最新已确认 MVP 范围（2026-10-10）**：**Agent 登记、Agent 执行日志采集、看板展示**。以 [17 当前 MVP](17-agent-log-dashboard-mvp.md) 为准。原型 HTML [保持不变](../prototype/index.html)，前端 Vue 3 + TypeScript + Vite 已确认。
>
> 本文件中字段/具体页面交互是开发建议，尚需用实际 Agent 平台数据核验。

## 1. 用户与目标

集团管理层：查看已登记 Agent、技术执行量、稳定性趋势与部门分布；部门/技术负责人：维护 Agent，查看失败原因与最近执行记录。

**平台不执行 Agent 的业务，也不代替 Agent 平台做运维控制**。首期只统一展示运行记录，不能对外声称已核验“业务任务成功”“实际节省工时”“财务成本/ROI”。

## 2. P0 页面需求

| 页面 | 功能 | 核心交互 |
| --- | --- | --- |
| **总览** | 数字员工(=Agent)卡片、部门分组、Run 总量/成功率/平均耗时、趋势与排行 | 点击卡片查看详情，按时间/部门筛选（如果 UI-F1 需要） |
| **Agent 登记管理** | 简单列表、创建、编辑、启用/停用 | Agent 平台+环境+原平台 ID 唯一，昵称可重复；简易表单 |
| **Agent 详情** | 基本资料、技术运行指标、按时间排序的 Run 和错误摘要 | 点击运行记录可查看该 Run 的必要字段/脱敏日志 |
| **监控中心** | 最近执行、失败记录、最近采集时间 | 只读；原型的处理/忽略是 Demo 行为，不作为正式操作 |
| **原型五场景** | 视觉忠实复刻静态场景说明 | Demo 环境可导航；不接场景流程编排/审批配置 |

**UI 还原原则**：UI-F0 的原型 CSS、四页布局、导航、演示行为逐项复刻；UI-F1 **保留几何结构**，在相同卡片/图表位置把演示文案及数据替换成 Agent 技术执行指标。管理表单可通过授权的子入口/独立路由增加，不改变原型两个一级导航。

## 3. Agent 登记表单（P0）

必填：显示名称、来源平台、原平台 Agent ID、环境、归属部门、负责人/联系角色。可选：简介、图标、启用状态（默认启用）。

- 一条登记记录 = 一名数字员工；一个 Agent 可有多条运行 Run。
- `enabled` 仅代表**本平台管理/采集是否启用**，不等于源 Agent 实际在线或停止运行。
- 首期不需要 Capability、复杂绑定、自动发现、员工审核、版本治理、部门数据审批工作流。

## 4. Run 日志采集（P0）

至少能够识别 `agent_id + run_id` 唯一执行、真实状态、开始或结束时间和平台接收时间；尽可能采集耗时、错误代码、可选 Token 输入/输出。

- P0 优先调用方或 Agent Gateway 通过鉴权的 HTTP API 上报 Run 结果；若源平台只开放日志查询，可用**针对这一平台的简单只读适配**。不用通用 Connector 管理门户。
- 同一 Agent Run 重试上报不应重复计量；状态更新遵循合法顺序。
- 正式环境不主动采集敏感 Prompt/Response、业务单据、手机号和完整工具输入输出；日志摘要须脱敏。
- API 故障不阻断原 Agent 运行业务。

## 5. 看板指标

| 指标 | 口径建议 | 无数据情况 |
| --- | --- | --- |
| 登记 Agent 数 | 按环境/部门/启用状态过滤的 `dw_agent` 记录数 | 无 Agent 可以是真实 0 |
| Agent Run 次数 | 查询窗口内唯一运行次数；以 `started_at` 为主，时间字段不足时明确采用的回退口径 | 尚未接入返回“未接入”，而不是原型固定量 |
| 技术执行成功率 | 已结束 Run：成功 / (成功 + 失败)，取消/运行中单列 | 无已完成样本显示“—” |
| 平均执行耗时 | 有效已结束 Run 的 `duration_ms` 平均值，不能把缺失耗时当 0 | “— / 暂无数据” |
| 失败数/失败列表 | 状态 FAILED 的唯一 Run 及脱敏错误 | 真实 0 与没有数据明确区分 |
| Token 用量（可选） | 源平台真实使用量之和 | 源未提供则不显示 |

**不得把 Agent Run 成功率命名为“业务成功率”**，也不得拿 Run 耗时乘一个想象单价计算成本。节省工时/ROI 不属于本期。

## 6. 非功能与验收

- 页面继续保持原型视觉 1:1 基准；正式数据源不包含 Demo 自动递增。
- 服务端 Agent 登记和日志查询具备最小授权、分页、参数校验和日志脱敏。
- Agent + Run ID 唯一：重复上报不得把执行数从 1 变为 2。
- Demo 9 人样本不默认写入生产 Agent 目录。
- 成功/失败/运行中按技术日志真实计算，断流显示“最近采集时间”。
- 首页总 Run 量与按 Agent 汇总一致（相同时间窗/过滤范围）。
