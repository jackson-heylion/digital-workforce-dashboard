## 查看页面

克隆仓库后：

```bash
python3 -m http.server 8000 --directory prototype
```

在浏览器打开 `http://localhost:8000/`。

也可以直接用浏览器打开 `prototype/index.html`，但为保持后续前端移植的一致开发体验，建议采用静态服务器方式。图表需要可访问 ECharts CDN。**GitHub 文件链接是源代码预览，不代表 GitHub Pages 已启用。**

## 前端还原规范

**UI 和交互的基础验收以这个 HTML 为准**，而不是以 PRD 里的 ASCII 示意图为准。详见 [UI 还原基准与验收清单](../docs/08-ui-reproduction.md)。

1. 第一轮：先 1:1 保留页面**导航结构、相对布局、间距、配色、卡片、图表、响应式和二级页交互**，不要自行把原有两级页面重设计成完全不同的“管理驾驶舱”。
2. 第二轮：把硬编码模拟数据隔离成 Demo Provider；业务真实接口通过 Data Provider/服务层替换，保留 Demo 切换与明显标识。
3. 第三轮：在不破坏页面的前提下，根据**已确认“管理层优先”**的方向，逐步调整指标真实度、重点顺序和下钻；任何明显改变布局的设计需单独评审。
4. 使用真实数据后，员工/业务状态、任务粒度、成本/工时口径遵循 [指标契约](../docs/04-metrics-and-contracts.md)，不能直接沿用原型演示值。

## 防止源文件被意外覆盖

原始文件位于 `prototype/index.html`，视为只读对照基准。未来 Vue/React 等应用的页面源码放在单独的 `web/` 或 `frontend/` 目录，**不要将改造后的前端构建结果覆盖这个文件**。若需要修改参考原型，先另建版本或在 PR 中注明差异与原因。
